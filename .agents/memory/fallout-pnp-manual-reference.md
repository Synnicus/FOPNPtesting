---
name: Fallout PnP manual reference scope
description: Coverage and source hierarchy for the in-app Quick Rules reference.
---

Use the Fallout PnP 2.0 manual’s table of contents and index to organize a searchable reference of rule-bearing sections and tables, with printed-page citations. Paraphrase the rules rather than copying page text.

Keep detailed item catalogs (weapons, ammunition, armor, chems, vehicles, traps) and creature stat blocks in the app’s existing Equipment and Bestiary tabs. The reference should explain their mechanics and point to those catalogs instead of duplicating their entries.

**Why:** The user selected “all rules and tables” for the expanded reference; the item and creature catalogs already have dedicated app tabs.

**How to apply:** When extending or correcting Quick Rules, preserve the manual’s part/chapter organization and search coverage while using the manual—not current app mechanics—as the authority for cited rule text.
