---
name: Custom consumable mechanics
description: Scope rule for effects entered on campaign-specific consumable records.
---

Custom consumable effect notes are reference-only; do not automatically modify character stats, HP, radiation, conditions, or combat until the user defines those mechanics.

**Why:** The consumable catalog request did not specify mechanical rules, so applying effects would invent behavior.

**How to apply:** Keep custom consumables descriptive and GM-adjudicated unless a later request explicitly adds automated effects.
