---
name: Fallout PnP scrollable tab interaction
description: Interaction requirements for tab groups that overflow in the mobile layout.
---

For horizontally overflowing tab groups, preserve touch swiping and provide visible arrow controls plus mouse dragging in the web preview.

**Why:** The user confirmed this combination scrolls correctly while using a mouse with the mobile-sized app preview.

**How to apply:** Keep these interaction modes when updating overflowable tabs in the character creator, Bestiary, or Equipment.
