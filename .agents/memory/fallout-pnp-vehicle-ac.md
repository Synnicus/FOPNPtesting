---
name: Fallout PnP vehicle AC
description: User decision for built-in vehicle armor class when the manual omits model-specific AC.
---

Built-in vehicles start at AC 0 when the manual does not provide a value; keep AC editable for custom or table-adjudicated values.

**Why:** the user explicitly chose AC 0 as the default for built-in vehicles.

**How to apply:** preserve this default when adding or importing manual vehicle profiles; do not infer AC from speed, structure, or DR.
