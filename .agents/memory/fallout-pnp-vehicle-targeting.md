---
name: Fallout PnP vehicle targeting
description: User-defined rules for vehicle subsystems and movement modifiers in combat.
---

Vehicle targeted-shot choices follow the current defender and use that vehicle's systems instead of humanoid body locations. Vehicle movement is on by default and applies −10% to hit; stationary vehicles apply no penalty. The modifier has no effect when the defender is not a vehicle.

**Why:** the user explicitly chose defender-matched target parts and a movement-based accuracy penalty.

**How to apply:** derive target choices and movement modifiers from the current defender each time; never let a prior vehicle's movement setting affect a nonvehicle target.
