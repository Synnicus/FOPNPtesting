---
name: Fallout PnP vehicle targeting
description: User-defined rules for vehicle subsystems and movement modifiers in combat.
---

Vehicle attacks require an explicitly selected vehicle system but retain the weapon's legal fire modes. Vehicles need no human body-part penalty; moving targets use the existing −10% penalty. Explosive damage hits Structure and the selected system (only once if Structure is selected). EMP affects only the selected electronic system, never Structure, tires, or treads. Anti-tank attacks commonly target Structure/Engine; mines commonly target Drive or tires/treads.

**Why:** the user explicitly chose defender-matched system targeting, retained fire modes, Structure-plus-selected blast damage, and electronics-only EMP damage.

**How to apply:** derive target choices from the current defender; require the system before rolling or applying vehicle damage; never let vehicle movement modifiers affect nonvehicle targets. Keep anti-tank and mine system guidance available without removing other legal choices.
